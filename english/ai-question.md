# AI 出题详解

AI 出题是广学英语的核心功能。用户在单词本选中若干单词后，由 AI 基于这些单词生成对应题型的练习题，题目进入队列后即可作答。

## 出题入口

- **单词本**：选中单词 → 工具栏「批量操作 → AI 出题」
- **答题页巩固练习**：作答完毕后点「巩固练习」，基于本题单词再出一道

两者都会打开同一个「AI 出题」对话框（`AIQuestionTypeSelector`）。

## 通用选项

对话框最上方的「选项设置」区有三个复选框（设置会持久化到 `localStorage`）：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 开启遗忘曲线 `NEW` | 开 | 按遗忘曲线 × 错误次数加权抽词；关闭则等概率随机抽取 |
| 包含这些词的关联词 | 关 | 把选中单词的关联词（不同形 / 易混）以较低概率加入候选池，AI 可考察其任意释义 |
| 允许改变形式 | 开 | 仅对「选词填空」生效：答案允许使用单词的变形（如时态、单复数） |

> 「开启遗忘曲线」的算法见[《遗忘曲线》](/english/forgetting-curve.md)。

## 七种题型

| 题型 ID | 名称 | 说明 | 题量上限 | 干扰词 |
| --- | --- | --- | --- | --- |
| `fill-blank` | 选词填空 | 根据句子上下文，从候选词中选词填空 | n≤11，n+m≤11 | 支持 m |
| `translate` | 翻译句子 | 将中文句子翻译成英文，每题必用一个指定词 | n≤5 | 无 |
| `meaning-select` | 英译中 | 四选一选择中文释义 | n≤10 | 无 |
| `meaning-select-en` | 英英释义 | 四选一选择英文释义 | n≤10 | 无 |
| `definition-fill-blank` | 词义填空 | 根据英文释义从候选词中选出正确单词 | n≤11，n+m≤11 | 支持 m |
| `word-select-translate` | 选词翻译句子 | 用指定候选词翻译中文句子 | n≤5，n+m≤可用词池 | 支持 m |
| `word-card` | 单词卡片 | 生成可翻转的单词卡片，正面单词背面释义 | 选中词全部 | 无 |

其中 `n` 为题目数量，`m` 为干扰词数量（多余单词，不作为答案目标，仅用于干扰）。

## 题目参数说明

- **可用单词池**：选中单词数；若开启「包含关联词」，再加上关联词数。
- 当 `n` 或 `n+m` 超过可用单词池时，对话框会报错并禁用生成按钮。
- 切换「包含关联词」或选词变化时，各题型的 `n` / `m` 会自动夹取到合法范围。

## 生成与批改流程

1. 选定题型与参数后点「生成」，后端先创建一条 `QuestionQueue` 记录（状态 `GENERATING`），再调用对应 Server Action 生成题面。
2. 题面生成成功 → 状态变 `GENERATED`，跳转到题目列表；失败 → `FAILED`，可重试。
3. 用户在[答题页面](/english/manual.md#答题页面)作答并提交。
4. 客观题（填空、选择）由后端自动判分；翻译题由 AI 批改给出 0–10 分。
5. 批改完成 → 状态变 `ANSWERED`，并调用 `recordReviewFromQuestion` 更新每个目标单词的复习状态。

## 题目状态流转

```
GENERATING ──生成成功──> GENERATED ──提交作答──> GRADING ──批改成功──> ANSWERED
     │                       │                     │
     └──生成失败──> FAILED    └──(重置)──> GENERATED └──批改失败──> GRADING_FAILED
```

`FAILED` / `GRADING_FAILED` 均可在题目列表中重试；重试 `FAILED` 会重新生成题面，重试 `GRADING_FAILED` 会重新批改。

## 选词逻辑

`selectWordsForQuestion` 负责从用户选中的词池里抽出真正进入题目的单词：

- **候选池 ≤ 所需数量**：返回全部选中词，并保留「关联词依赖闭包」（若 A 的关联词 B 也在选中列表，则必须同时带上 B）。
- **候选池 > 所需数量 + 关闭遗忘曲线**：Fisher-Yates 等概率洗牌取前 N 个。
- **候选池 > 所需数量 + 开启遗忘曲线**：按 `totalWeight = f(t) × g(e)` 加权无重复抽样（Efraimidis-Spirakis 算法）；所有词权重都为 0 时回退等概率抽样。

> 关联词仅作为干扰项或可选释义对象出现，不参与复习状态更新与 quality 计算。

## AI 调用封装

- `src/lib/openai.ts`：OpenAI 兼容接口封装，支持多模型配置、自动重试、超时、降级模型。
- `src/lib/ai-queue.ts`：`AIRequestQueue` 限制并发（默认 3），防止触发模型限流。
- 模型配置通过环境变量 `LLM_CONFIGS`（JSON 数组）注入。

## 导出 PDF

题目列表与单词本均支持导出 PDF，由 `src/lib/pdf-generator.ts` 基于 `jsPDF` + `html2canvas` 生成。题目 PDF 会包含题面与参考答案。
