## 网站概述

广学英语围绕「生词本」组织学习闭环：把生词加入单词本 → 由 AI 基于这些生词生成练习题 → 在题目列表中作答 → 系统自动批改并更新每个词的遗忘曲线状态 → 下次出题时优先抽取快要遗忘或常出错的词。作文积累本作为独立模块，与单词本共用标签。

> 遗忘曲线的算法细节请见[《遗忘曲线》](/english/forgetting-curve.md)，AI 出题的题型与参数请见[《AI 出题详解》](/english/ai-question.md)。

## 页面导航

登录后顶部导航栏包含四个入口：

| 入口 | 路径 | 说明 |
| --- | --- | --- |
| 单词本 | `/` | 生词本主页，管理单词与发起 AI 出题 |
| 作文积累 | `/writing` | 作文素材积累本（独立模块，本文档不作介绍） |
| 题目 | `/practice` | 题目队列列表，进入答题 |
| 设置 | `/settings` | 标签管理 |

未登录时首页显示登录入口，点击后会跳转广学账号完成单点登录。

## 单词本

单词本是平台的核心。页面顶部为工具栏，下方为单词卡片网格，每张卡片展示单词文本、释义、标签、关联词以及遗忘曲线权重。

### 添加单词

1. 点击工具栏的「添加单词」按钮（`+`），打开单词编辑弹窗。
2. 输入单词后，系统会自动调用内置词典（`ecdict.csv`）查询并回填释义，用户可只勾选自己不熟悉的释义。
3. 可选：为单词打标签、添加关联词（同形异义词 `different_form` 或易混词 `easily_confused`）。
4. 保存后单词即入库，单词文本对同一用户唯一。

> 还可通过「批量添加」一次录入多个单词，或通过「拍照识词」从图片识别生词。

### 管理单词

- **选择**：单击卡片复选框选择单词；工具栏可开启「区间选择」模式，单击首尾两个词即可选中区间内全部单词。
- **搜索**：工具栏搜索框对单词文本和释义进行模糊匹配。
- **筛选**：按标签筛选，支持「交集 / 并集」两种逻辑。
- **排序**：默认按修改时间倒序，可切换为字母序。
- **编辑 / 删除**：单击卡片进入编辑；选中后点「批量操作」可批量删除或批量打标签。
- **遗忘曲线权重**：每张卡片底部展示三个数值——总权重 = `f(t) × g(e)`、遗忘权重 `f(t)`、错误权重 `g(e)`，数值越大越优先被抽取出题。

### 标签管理

标签在单词本和作文积累本之间共用。完整的新建 / 编辑 / 删除在[设置](#设置)页进行；在添加 / 编辑单词弹窗内也可直接选用已有标签。每个标签可配置名称、颜色、描述。

### 拍照识词

1. 点击工具栏「拍照识词」按钮，上传一张纸质资料照片。
2. 图片会先被压缩（大于 1MB 时），发送给 PaddleOCR 服务。
3. 系统先做透视变换与光照归一化，再 OCR 识别全部单词，最后通过 HSV 颜色检测找出被高亮标记（荧光笔、下划线、圆圈等）的单词。
4. 识别结果会逐个回填释义，用户勾选要入库的单词与释义后一键保存。

> 拍照识词依赖本地 `paddleocr-service`（端口 39821），开发时 `pnpm dev` 会自动启动它。

### 导出单词本

工具栏提供「导出 PDF」功能，可把当前单词本（或选中单词）导出为排版好的 PDF，便于打印复习。

### AI 出题入口

选中若干单词后，点击工具栏「批量操作 → AI 出题」，会打开 AI 出题对话框。题型的选择与参数配置请见[《AI 出题详解》](/english/ai-question.md)。生成完成后会自动跳转到题目列表。

## 题目列表

路径 `/practice`，展示当前用户的所有题目（按创建时间倒序）。

每条题目显示：题型、状态、创建时间、涉及单词数。

题目状态有以下几种：

| 状态 | 含义 |
| --- | --- |
| `GENERATING` | AI 正在生成题面 |
| `GENERATED` | 题面已就绪，等待作答 |
| `ANSWERED` | 已作答并批改完成 |
| `FAILED` | 生成失败 |
| `GRADING` | 正在 AI 批改 |
| `GRADING_FAILED` | 批改失败 |

列表页操作：

- 点击题目进入[答题页面](#答题页面)。
- 单道 `FAILED` / `GRADING_FAILED` 题目可点「重试」重新生成或批改。
- 多选后可「批量重试」。
- 可将题目「导出 PDF」（含题面与答案）。

### 答题页面

路径 `/practice/[questionId]`，根据题型渲染不同的作答界面：

| 题型 | 作答方式 | 批改方式 |
| --- | --- | --- |
| 选词填空 | 在句子空格中填入候选词 | 自动判分（精确匹配） |
| 翻译句子 | 文本框输入英文翻译 | AI 批改（0–10 分） |
| 英译中 | 四选一选择中文释义 | 自动判分 |
| 英英释义 | 四选一选择英文释义 | 自动判分 |
| 词义填空 | 根据英文释义填入候选词 | 自动判分 |
| 选词翻译句子 | 用指定候选词翻译中文句子 | AI 批改（0–10 分） |
| 单词卡片 | 点击卡片翻转查看释义 | 不批改（仅浏览） |

题面若仍在生成（`GENERATING`），页面会显示「题目正在生成中」，就绪后自动刷新。

### 作答完毕

提交答案后：

1. 系统按题型执行自动判分或 AI 批改，状态变为 `ANSWERED`。
2. 批改结果（每道小题的得分 / 对错）展示在题面下方。
3. 系统根据批改结果反推每个目标单词的 `quality`，更新其 `WordReviewState`（SM-2 状态 + 错误次数），详见[《遗忘曲线》](/english/forgetting-curve.md)。
4. 页面底部出现「巩固练习」按钮，可基于本题的单词再生成一道新题继续练习。
5. 空答案的小题视为「放弃」，按错误处理（quality=1），更新该词的遗忘曲线（errorCount+1、interval 重置）。`word-card` 类型不适用。

> 若批改失败（`GRADING_FAILED`），不会更新复习状态，可在列表页重试批改。

## 设置

路径 `/settings`，目前提供「标签管理」：新建 / 编辑 / 删除标签，配置名称、颜色、描述。标签变更会同步反映到单词本和作文积累本。

## 登录与登出

- **登录**：未登录时点击首页登录按钮，跳转广学账号 SSO 完成登录后回调本站，写入 HTTP-only Cookie（有效期 7 天）。详细流程见[《登录与单点登录》](/english/auth.md)。
- **登出**：点击导航栏用户名旁的「登出」按钮，清除会话并刷新页面。
