# 🧬 遗传学模拟器 — 游戏规则文档

## 一、游戏概述

遗传学模拟器是一个基于经典遗传学原理的推理挑战游戏。玩家需要通过**杂交实验**观察后代表现型比例，然后构建**遗传理论模型**来解释实验结果，最终提交验证以判断理论是否正确。

游戏核心循环：

1. **观察** — 在杂交实验室中对亲本进行交配，观察后代性状分离比
2. **推理** — 根据实验数据，推断基因型、显隐性关系、致死机制等
3. **构建** — 在理论构建区搭建遗传规则树，设定亲本基因型
4. **验证** — 提交理论，系统通过 SPJ（Special Judge）自动判定正误

## 三、杂交实验室

### 3.1 基本操作

1. **选择个体**：点击家系图中的个体节点，依次选中个体 A 和个体 B
2. **交配方式**：
   - **杂交**：选择两个不同个体后点击"杂交"按钮
   - **自交**：仅选择一个个体后点击"自交"按钮（仅限非伴性遗传）
   - **随机交配**：仅选择一个个体后点击"随机交配"按钮（仅限非伴性遗传），模拟该表现型群体内随机交配
3. **查看结果**：杂交后后代自动添加到家系图中，顶部显示各表现型及比例

### 3.2 交配规则

- **常染色体遗传**：可选择自交、杂交或随机交配
- **伴性遗传**：必须选择一雌一雄两个个体进行杂交，不允许自交
- **同性交配**：伴性遗传模式下，同性个体之间不能交配
- **后代命名**：后代以 `F{代数}_{序号}` 格式命名，如 F1_1、F2_3

### 3.3 家系图操作

- **点击个体**：选中/取消选中该个体
- **删除后代**：悬停后代节点，点击右上角 ✕ 可删除该个体及其所有后代
- **缩放/平移**：鼠标滚轮缩放，拖拽空白区域平移
- **清除选择**：点击"清除"按钮取消所有选中

### 3.4 结果解读

杂交结果会显示：
- 各表现型名称
- 各表现型对应的后代数量（比例）
- 化简后的比例（如 3:1、9:3:3:1）

## 四、理论构建区

理论构建区是游戏的核心，分为左侧面板和右侧画布。

### 4.1 基因列表

| 操作 | 说明 |
|------|------|
| 添加基因 | 点击"添加基因"按钮，最多 5 个基因 |
| 删除基因 | 点击删除按钮，至少保留 1 个基因 |
| 等位基因数 | 每个基因支持 2~5 个等位基因 |
| 染色体分配 | 下拉选择将基因分配到不同染色体 |

基因命名规则：
- 2 个等位基因时：大写字母（显性）和小写字母（隐性），如 A/a
- 3 个及以上等位基因时：字母加数字编号，如 I1、I2、I3

### 4.2 染色体映射

系统支持 7 条染色体：

| 染色体 | 类型 | 说明 |
|--------|------|------|
| chr1~chr5 | 常染色体 | 不同染色体上的基因自由组合 |
| chrX | X 染色体 | 伴 X 遗传，雌性 XX，雄性 XY |
| chrY | Y 染色体 | 伴 Y 遗传，仅雄性拥有 |

**操作方式**：从基因列表拖拽基因到目标染色体上。

**重要规则**：
- 同一染色体上的基因表现为**连锁**（不发生自由组合）
- 不同染色体上的基因表现为**自由组合**
- 当基因被分配到 chrX 或 chrY 时，系统自动启用伴性遗传模式

### 4.3 亲本基因型配置

根据是否为伴性遗传，亲本配置有所不同：

**常染色体遗传**：
- 亲本性别为"无性"
- 每个基因有两条等位基因（二倍体）
- 可添加多个亲本

**伴性遗传**：
- 亲本必须区分雌（♀）雄（♂）
- 雌性：chrX 上有两个等位基因，无 chrY
- 雄性：chrX 上有一个等位基因（半合子），chrY 上有一个等位基因
- 至少需要一个雌性和一个雄性亲本

### 4.4 性状判定树（核心机制）

性状判定树是定义基因型→表现型映射规则的核心工具。每个性状标签页对应一棵判定树。

#### 4.4.1 树的结构

- **根节点**：默认表现型（当没有任何规则匹配时的表现型）
  - 普通性状：根节点默认名为"白色"
  - 致死性状：根节点默认名为"正常"
- **子节点**：通过规则边连接到父节点，表示满足特定条件时的表现型
- **规则边**：从父节点指向子节点的有向边，标注转化条件

#### 4.4.2 规则边类型

| 类型 | 含义 | 判定逻辑 |
|------|------|----------|
| `has`（显性/具有） | 个体拥有该等位基因 | 基因型中至少一条染色体包含该等位基因 |
| `homo`（纯合） | 个体在该基因座上纯合 | 基因型中两条同源染色体都包含该等位基因 |

**示例**：
- `has A`：基因型中存在 A（AA 或 Aa 均满足）
- `homo A`：基因型中 A 纯合（仅 AA 满足）
- `homo a`：基因型中 a 纯合（仅 aa 满足）

#### 4.4.3 优先级

当一个节点有多条出边时，按优先级从小到大依次判定，**首次匹配即停止**。

**示例**（不完全显性）：
```
根节点(白色)
  ├── homo R (优先级1) → 红色
  └── has R  (优先级2) → 粉色
```
判定逻辑：先检查是否纯合 R → 是则红色；否则检查是否有 R → 是则粉色；都不满足 → 白色。

#### 4.4.4 操作方式

| 操作 | 方法 |
|------|------|
| 添加子节点 | 右键父节点 → "添加子节点" |
| 编辑节点名称 | 双击节点 或 右键 → "编辑名称" |
| 删除节点 | 右键节点 → "删除"（根节点不可删除） |
| 建立连线 | 从节点输出端口拖拽到另一节点 |
| 编辑连线条件 | 点击连线，在右侧面板修改条件类型和等位基因 |
| 管理优先级 | 右键节点 → "管理优先级"，用箭头调整子边顺序 |

### 4.5 性状标签页类型

| 类型 | 说明 |
|------|------|
| 普通性状 | 定义表现型，如颜色、形态等 |
| 胚胎致死 | 定义致死条件，满足条件的个体在胚胎期死亡，不参与后代统计 |
| 配子致死 | 定义配子致死条件，含致死等位基因的配子无法存活 |

**操作**：
- 点击"添加性状"可新增普通性状标签页（最多 5 个非致死性状）
- 胚胎致死和配子致死标签页默认各一个
- 在致死标签页中，单击节点可切换"正常 ↔ 致死"状态

## 五、遗传学概念与模型

### 5.1 分离定律

一对等位基因的遗传：

```
Aa × Aa → 3 黑色(A_) : 1 白色(aa)
```

判定树：
```
白色 → has A → 黑色
```

### 5.2 自由组合定律

两对或多对位于不同染色体上的基因独立遗传：

```
AaBb × AaBb → 9 黑高 : 3 黑矮 : 3 白高 : 1 白矮
```

需要两棵独立的判定树，分别判定 A 基因和 B 基因。

### 5.3 连锁

位于同一染色体上的基因连锁遗传，不发生自由组合：

```
AB/ab × ab/ab → 1 黑高(AB/ab) : 1 白矮(ab/ab)
```

将两个基因分配到同一条染色体即可实现连锁。

### 5.4 不完全显性

杂合子表现中间性状：

```
Rr × Rr → 1 红色(RR) : 2 粉色(Rr) : 1 白色(rr)
```

判定树（利用优先级）：
```
白色 → homo R (优先级1) → 红色
      → has R  (优先级2) → 粉色
```

### 5.5 复等位基因

一个基因座有 3 个及以上等位基因（如 ABO 血型）：

```
IAi × IBi → 1 A型 : 1 B型 : 1 AB型 : 1 O型
```

判定树：
```
O型 → has IA (优先级1) → A型 → has IB → AB型
     → has IB (优先级2) → B型
```

### 5.6 伴性遗传

基因位于性染色体上，表现与性别相关：

**伴 X 遗传**：
- 雌性（XX）：两条 X 染色体，可为纯合或杂合
- 雄性（XY）：仅一条 X 染色体，半合子，X 上的基因直接表现

```
X^A X^a ♀ × X^a Y ♂ → 1 X^A X^a(♀黑) : 1 X^a X^a(♀白) : 1 X^A Y(♂黑) : 1 X^a Y(♂白)
```

**伴 Y 遗传**：
- 仅雄性拥有 Y 染色体，Y 上的基因只在雄性中表现
- 父传子，全雄性后代表现该性状

### 5.7 胚胎致死

特定基因型在胚胎期致死，不出生：

```
Aa × Aa（AA 致死）→ 2 黑色(Aa) : 1 白色(aa)
```

判定树：
- 性状树：`白色 → has A → 黑色`
- 胚胎致死树：`正常 → homo A → 致死`

### 5.8 配子致死

含特定等位基因的配子无法存活：

```
Aa × Aa（a 配子致死）→ 全部黑色(AA)
```

配子致死树：
```
正常 → has a → 致死
```

配子致死树判定的是配子而非个体，含致死等位基因的配子不参与受精。

### 5.9 上位效应

一个基因的表现掩盖另一个基因的表现：

**隐性上位**（如 epistasis）：
```
AaBb × AaBb → 9 有色(A_B_) : 3 黑色(A_bb) : 4 白化(aaB_ + aabb)
```

**显性上位**：
```
AaBb × AaBb → 12 白色(A_) : 3 黑色(aaB_) : 1 棕色(aabb)
```

## 六、验证机制（SPJ）

### 6.1 验证流程

点击"提交验证"后，系统执行 Special Judge（SPJ）：

1. **谱系图验证**：从用户指定的 **亲本基因型** 尝试推导整个谱系图的基因型。检查用户构建的家系图中，每个杂交组合的后代比例是否与真实系统一致
2. **随机交叉验证**：进行 10 轮随机杂交实验，比较用户理论与真实系统的后代比例是否一致
3. **比例比较**：归一化后比较表现型比例，容差为 1%

### 6.2 通过条件

用户构建的理论系统必须在所有验证步骤中产生与真实系统完全一致的后代比例，才能通过验证。

### 6.3 常见失败原因

- 显隐性判断错误（`has` vs `homo`）
- 遗漏致死基因（未设置胚胎致死或配子致死）
- **亲本基因型推断错误**
- 优先级设置不当导致判定顺序错误
- 染色体分配错误（连锁 vs 自由组合）

## 七、创建题目

### 7.1 创建流程

1. 在题目列表页点击"创建新物种"
2. 设置题目名称
3. 配置基因列表（名称、等位基因数、染色体分配）
4. 构建性状判定树（普通性状 + 致死机制）
5. 设定亲本基因型
6. 点击"发布到公共题库"

### 7.2 验证规则

发布前系统会自动检查：
- 所有性状树必须有根节点
- 所有规则边必须指定等位基因条件
- 不存在未连接的孤立节点
- 不存在环（必须是树结构）
- 每个非根节点有且仅有一个入边
- 亲本不能纯合胚胎致死基因（否则该亲本不可能存活）

### 7.3 编辑题目

只有题目作者可以编辑自己的题目。编辑页面会加载原有数据，修改后点击"保存修改"。

## 十、术语表

| 术语 | 解释 |
|------|------|
| 基因型 (Genotype) | 个体在基因层面的组成，如 Aa、BB |
| 表现型 (Phenotype) | 个体可观察的性状，如黑色、白色 |
| 等位基因 (Allele) | 同一基因的不同形式，如 A 和 a |
| 纯合 (Homozygous) | 两条同源染色体上等位基因相同，如 AA |
| 杂合 (Heterozygous) | 两条同源染色体上等位基因不同，如 Aa |
| 半合子 (Hemizygous) | 仅有一条染色体上有该基因（如雄性的 X 染色体基因） |
| 显性 (Dominant) | 杂合时表现出的等位基因 |
| 隐性 (Recessive) | 杂合时被掩盖的等位基因 |
| 连锁 (Linkage) | 同一染色体上的基因一起遗传 |
| 自由组合 (Independent Assortment) | 不同染色体上的基因独立分配 |
| 上位效应 (Epistasis) | 一个基因影响另一个基因的表现 |
| 胚胎致死 (Embryo Lethal) | 特定基因型导致胚胎死亡 |
| 配子致死 (Gamete Lethal) | 特定等位基因导致配子死亡 |
| 伴性遗传 (Sex-linked Inheritance) | 基因位于性染色体上的遗传方式 |
| SPJ (Special Judge) | 特殊评判程序，通过比较后代比例验证理论正确性 |
